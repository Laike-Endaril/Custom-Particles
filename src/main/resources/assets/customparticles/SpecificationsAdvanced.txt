======================================================================================================================================================================
======================================================================== PATH FUNCTIONS ==============================================================================
======================================================================================================================================================================



constant / position / pos
Defines a constant path, ie position.
You can technically add as many numbers to it as you want, but most likely only 1 or 3 numbers will get used, depending on what you pass it to.


linear / speed / rate
Defines a linear path, ie speed or rate.
You can technically add as many numbers to it as you want, but most likely only 1 or 3 numbers will get used, depending on what you pass it to.
