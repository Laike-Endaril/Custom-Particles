NOTES =========================================================================================================================

A lot of the logic is moved to another thread, so it won't show up on profiling for the normal threads
Watch out for "Tick-based particle emitters skipped x ticks in the last second" in the console
"/omni threads" can be used for very rough profiling

Particles in unloaded chunk sections are rendered black when using block light level, due to a vanilla lighting bug
Probably only when the block they're currently in "can't see sky"

Particles currently render in front of translucent blocks even when inside / behind them (but not solid or cutout blocks, thanks to the z buffer)
To fix this properly, I would need to render all translucents (blocks, entities, and particles) in furthest-to-nearest order.  That's not happening unless I rewrite minecraft's rendering engine entirely, ie. optifine-like mod.  Not doing that right now
